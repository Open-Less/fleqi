# Fleqi 文档索引

产品文档使用简体中文；PRD 需求编号（A0-xx）在各文档中保持一致。文档按类别归档如下。

## 目录分类

| 目录 | 内容 |
| --- | --- |
| `product/` | 产品需求基线：`Fleqi_PRD_v0.0.1_Final.md` |
| `engineering/` | 架构与工程准备：`P0_Architecture_and_Preparation.md`；仓库与持续集成：`Repository_and_CI.md`；发布与分发：`Release_and_Distribution.md`；GitHub 账号与自动更新：`GitHub_and_Updates.md` |
| `design/` | 界面规范：`P0_UI_Spec.md`；动效与字体：`UI_Motion_and_Typography.md` |
| `qa/` | 验收记录：`P0_Acceptance.md`（含 PRD 对照与未覆盖场景） |
| `licenses/` | 第三方许可：BorderBeam、shadcn |
| `previews/` | 界面截图与动效演示（浏览器预览证据，不证明原生挂靠与真实账号行为） |

## 建议阅读顺序
