# Fleqi 动效与字体规范

本规范执行“从哪来、到哪去”：出现和消失属于同一条路径，收起动画完成后才移除内容。覆盖工作区、独立设置、模型表单、菜单、底部栏和反馈信息。

## 统一曲线

唯一配置源为 [`src/motion/tokens.json`](../../src/motion/tokens.json)。React、CSS 和 Swift 都读取这份配置。使用 `cubic-bezier(0.2, 0.8, 0.2, 1)`，快速响应后平滑减速，不使用弹跳或过冲。

| 动作 | 时长 | 来源与去向 |
| --- | --- | --- |
| 按钮、忙碌图标、底部栏显隐 | 140 ms | 保持控件位置，按压与释放互为反向；底部栏在 Finder 下沿淡入淡出 |
| 菜单、下拉选择、提示 | 220 ms | 根据 Radix 计算的触发点和展开方向进入，同方向反向收回 |
| 表单、内容区高度、主题与材质 | 280 ms | 从当前实际尺寸过渡到内容所需尺寸；新增内容从所属区块边缘出现 |
| 侧栏、设置与原生窗口 | 320 ms | 侧栏向左收起；弹窗围绕触发点从 96% 缩放到完整尺寸，关闭时返回 |

输入框收拢与展开单独使用 `duration.composer = 0.52`（520 ms），保持右边沿不变；进度底色不透明度为 30%，工具名称向右滚动。减少动态效果时冻结位移与旋转，阶段文字仍显示。

页面切换按导航顺序确定方向。关闭与反向操作沿原来的展开路径收回，保留退出期间的内容，避免直接移除导致闪烁。后台任务不因视觉收起被取消。

## 组件用法

- `Dialog` / `DialogContent`：统一捕获鼠标或键盘触发点，保留关闭过程，并在结束后归还焦点。
- `Reveal`：用于需要展开、收回的上下文、斜杠菜单、问题和错误提示；底部栏使用 `edge="bottom"`。
- `AutoHeight`：观察自然内容尺寸，平滑改变外层高度。测量不包含父元素缩放，避免弹窗缩放时算错高度。
- `PageTransition`：用于设置分类、工作区页面和连接方式切换；旧内容退出期间不可继续交互。
- Radix 菜单、选择器、Sheet、Collapsible、Switch 使用同一份 CSS 曲线。新增模块优先复用这些组件。

底部弹出区域通过 `ResizeObserver` 报告单一浮层的实际高度，串行合并原生尺寸请求；网页底栏绝对贴视口底边，不因窗口扩展、气泡或菜单出现而移动。macOS 窗口由 `WindowMotion.swift` 处理，使用触发控件的屏幕坐标和共享曲线；连续开关通过版本编号忽略过期完成回调。主题与原生玻璃材质同步渐变。

## 字体与视觉

全界面共用 `--font-ui`。macOS 使用系统 SF 字体及苹方中文回退；Windows 使用 Segoe UI / 微软雅黑，其余平台使用系统无衬线字体。不再混用 Inter、单独的界面等宽字体或浏览器默认表单字体。快捷键、路径与数字沿用同一字体，必要处启用等宽数字。

保留 shadcn 的灰、黑、白语义色，以及 400 / 500 / 600 字重层级。标题、正文和辅助文字保留不同字号。参考场景的静态 Finder 图片属于素材，其像素字体不参与界面字体替换。

## 验证与可访问性

`tests/motion.spec.ts` 逐帧检查弹窗进出、侧栏中间宽度、表单中间高度、输入框底边、菜单曲线、焦点与快速关闭。字体检查比较标题、输入框、菜单和按钮的实际字体栈。

“减少动态效果”开启时立即进入最终布局，禁用位移与缩放；功能和键盘操作保留。原生动画读取 macOS 的同一系统偏好。

[动效演示](../previews/motion-demo.webm)展示浏览器版本。原生窗口动画已接入并通过编译；本轮 Mac 锁屏，尚未完成新版原生画面实测。
